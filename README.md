# Pocket Crayon Workshop Inc.

Single-page, static corporate website for Pocket Crayon Workshop Inc. No build tools, backend, API keys or paid hosting required.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the Pages deployment; the default address should be `https://emilyaread-lab.github.io/pcw/` once published.
5. Later, add a custom domain in Pages settings and configure DNS as instructed by GitHub. Do not add a custom domain until you own it.

## Editing

Edit `index.html` to update copy, styles, links or contact details. Site contains no personal data collection or payment processing; those are handled by individual products. The Crew Closet support email is for **Crew Closet product support** and should not be presented as a general corporate contact.

Before using the site for Stripe verification, confirm all published company and product information is accurate and the product support and legal links work.
